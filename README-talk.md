## talk.bas - table talk for phext policies

`talk.bas` is a libphext-bas-adjacent include: the table-talk
layer for Cards and Casters policies built on this library. It
implements Will's directive (EE ~930-931) that a phext policy
explicitly offer table talk, accept input from the game and the
participants, support allies, deceive enemies, and keep an
evidence-driven, revisable trust track per seat.

Concatenate it after `libphext.bas` (it needs the phStore store
API) and bind four hooks in the host policy - the reference
binding is `bots/v37-tabletalk.bas` on the emise-baseline
chassis, generated by named hunks so the chassis stays auditable:

1. **Step** - `GOSUB tkStep` once per main decision, after the
   observation pass (it reads `phStrLeft`, the observation
   pass's leftover string budget, and drains at most one
   mailbox message per decision, only when >= 40 strings
   remain).
2. **Event hook** - in the observation pass's attack branch,
   `tkSeat = attacker : tkHookTarget = target owner : GOSUB
   tkObserveHook` (breach detection and coordination honor).
3. **Protection** - targeting code asks `tkSeat = o : GOSUB
   tkProt` and treats `tkP = 1` seats as untargetable while
   `tkFree >= 1` (an unprotected living outsider exists);
   `teamcalc` additionally adds -3 to the focus score of the
   shared-threat seat (`tkThreat`) and the agreed coordination
   target (`tkAgreeT`) while fresh (12 turns).
4. **State** - trust is the store's TENDENCY family (family 1,
   slot 4, phase 0), so talk evidence drifts with the chassis's
   own per-turn decay; discrete talk state is family 3 (free in
   the baseline map). See the header of `talk.bas` for the full
   grammar (`PX <verb> <sender> <x> <y> <z>`), the slot map, the
   eleven pre-stated mechanisms, and the budgets (2 broadcasts,
   8 sends per match, hard caps).

Failure discipline: the parser is a hand-rolled bounded scan
(no VAL, 24-char cap); malformed input increments a counter and
nothing else. Sends are counted before they happen against the
cap. The module never blocks a decision.

Tests: `tests/libphext-test-talk.bas` - parser, store, trust
lifecycle, and a mailbox round trip (a policy DMs itself a
PROPOSE and the handler inscribes the agreed target), in the
house harness style:

    cac-headless --bot libphext-test-talk.bas --bot warrior.bas \
      --seed 1 --verbose | grep TALKTEST
